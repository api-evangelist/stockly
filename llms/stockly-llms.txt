# Stockly

> Stockly (Stockly SAS, Vitry-sur-Seine, France) operates a global inventory network for e-commerce — "the first global inventory for Retail." It connects e-shops that are missing stock (Demanders) with brands and official retailers that have surplus inventory (Suppliers), filling out-of-stock variants in real time so retailers never run out. Backed by Techstars. Integration is API-driven: Stockly connects to a demander's e-commerce infrastructure (via API, a CMS, or a marketplace) rather than exposing a broad public developer API.
